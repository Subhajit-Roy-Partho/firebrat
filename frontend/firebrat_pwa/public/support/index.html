Report a bug

Open a GitHub issue

Include the app version, device/OS, conversion mode, model/voice selection, steps to reproduce, expected result and the visible error. A screenshot or a small public-domain sample is helpful.

GitHub issues are public. Remove passwords, tokens, API keys, personal information and private/copyrighted book content before posting. For private details, email royduck@duck.com.

Common fixes

  • Cannot reach the server: use Offline for imported books, or On-device for Android local conversion. Server mode requires a reachable server URL and network connection.
  • Local conversion needs a download: download the chosen language model and Kokoro voice data while online before testing offline.
  • Book will not open: verify the package finished importing/downloading. Keep a backup before deleting a local copy.
  • Conversion was interrupted: keep the device awake and allow the foreground conversion notification. Large models may need more memory; choose a smaller model or fewer GPU layers.
