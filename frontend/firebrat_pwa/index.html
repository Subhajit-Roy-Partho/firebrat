Novel mode preserves the extracted prose and uses the server’s character voice configuration.

Expressive voices is slower; each character gets their own voice. EPUB/MOBI or text PDF only.

The server looks the book up on Wikipedia and asks its LLM for each character’s age and temperament, so characters sound different. Only the title and character names are sent, never the book’s text.

One character per line. Ages: child, young, adult, elder. Temperaments: calm, cheerful, stern, gruff, gentle, energetic, mysterious. Also male or female.
