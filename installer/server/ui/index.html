Firebrat Server

Convert on this computer. Read and listen on your phone.

1. Choose how to prepare narration

Your provider receives book text for compilation. Audio is always generated here; no speech API is used. Your provider may charge for LLM requests.

Native Ollama can use Metal on Apple silicon. Speech uses CPU on Macs; compatible NVIDIA GPUs can accelerate speech on Linux.

Install Ollama

2. Prepare and start

First setup downloads Python and several GB of dependencies. Keep internet on until your first conversion has downloaded the extraction and voice models. Later local conversions can run offline.

Open your book library


3. Choose a book
Leave this launcher running during conversion. Completed books appear in the phone library when refreshed.


4. Connect your phone
Install Tailscale on this computer and your phone, and sign in to the same private network. Run:
tailscale serve --bg http://127.0.0.1:8000
Use the HTTPS address Tailscale prints as the server address in Firebrat. Or open that address followed by /pwa/ in your phone browser. Your computer must stay awake. This shares your library inside your tailnet; it does not make the setup screen public.
Tailscale Serve instructions
Only local desktop conversion uses this private setup screen. Uploading through the server's web control room or phone requires Firebase sign-in and connectivity.


Your books, model downloads and settings are kept when you stop.
