# Agent hand-offs

When you finish (or stop) a piece of the 2026-10-26 work stream, write `docs/handover/<area>.md` (backend.md, pwa.md, android.md, server-run.md, ...):
1. What you changed (files) and why; 2. exact commands you ran and their results (tests, builds); 3. what is NOT done or not verified;
4. gotchas the next agent must know; 5. what you would do next. Keep it factual. The lead folds the essentials into `docs/TASK.md`.
Do not edit another agent's handover file. Never put secrets in these files.
