## 4. Backend shapes coded against
- `GET /me` -> `{uid,email,name,role|null,iam_enabled,needs_setup}`; `GET /settings` -> `cast_available`, `iam_enabled`.
- `GET /admin/users` -> `{users:[{uid,email,name,role,status,created_at,invited_by,last_seen}], invites:[{email,role,claimed_uid,...}]}`. Tolerant: a bare array is accepted; claimed invites hidden.
- `GET /admin/audit?limit=` -> `{audit:[{at,actor_uid,action,target,...}]}` (bare array also tolerated).
- `PATCH/DELETE /admin/users/{uid|email}`; `POST /admin/users {email,role}` (email lowercased client-side). Pending invites are removed with DELETE by email.
- `GET /admin/settings` -> `{values, options, availability, notes}` with `options.llm.models[]`, `options.llm.quantizations[]`, `options.tts.engines[]` (entries `{id,name?,vram_gb,description,available}`),
  `options.run_pattern.{phase_modes,audio_orders,max_books_range}`. TOLERANT of flat shapes: `llm_models/llm_model/llm`, `tts_engines/tts_engine/tts`, `quantization`, `phase_mode`, `audio_order`; missing run_pattern lists default to the contract values, range to [1,20].
  `PUT /admin/settings {values}` sends the full values object (untouched keys such as `limits` are preserved from the GET).
- `GET /admin/queue` -> `{scheduler:{available,running,detail,status,books:[{slug,stage,detail,progress 0..1,terminal,error}]}, paused}` (a top-level `books` is also tolerated).
  `POST /admin/queue/pause|resume`; `POST /admin/queue/{slug}/cancel`; `POST /admin/queue/{slug}/priority {top:true}` (server returns 409 unless the job is queued; UI only offers "Move to top" when stage == 'queued').
- `POST /admin/bootstrap {code}`: 403 wrong code, 410 already set up, 429 lockout; all mapped to friendly text (`setupError`). 410 triggers a reload of `/me`.

## 5. Gotchas
- `request()` maps every 403 to the generic "not allowed" message, but sets `err.status/err.detail` so callers (setup) can show their own text. 401 still says "sign in again".
- Quiet hours semantics: window in which NO new GPU phase starts (overnight wraps); both fields or neither (validated client-side; start != end). Saved as `null` when empty.
- `max_books_per_llm_phase` must be a whole number in the server-reported range; the default fallback in the form is 4.
- Admin visibility: `showAdmin` = role admin and not in setup, regardless of `iam_enabled` (covers the legacy admin per `/me`); setup needs `iam_enabled` on `/settings` or `/me`.
- `canUpload` is permissive when `iam_enabled` is false. Cast option is hidden only for viewers; for signed-out users it exists but the form is disabled.
- Role dropdown change triggers an immediate PATCH and reloads the list (so a rejected last-admin demotion snaps back and shows the server's text).
- Queue polling uses the existing 4 s interval and only runs when the admin section is visible and the document is visible.
- The Playwright smoke script must resolve `playwright-core` from another project (none installed here); `npm run build` empties `backend/server/static/pwa`.
