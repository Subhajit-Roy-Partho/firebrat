# Modern Play listing

`exports/` holds the 1024x500 feature graphic and the eight 1080x1920 gallery images (`01`-`08`, in listing order) that Play accepts. The `extra-*` images are spare (the website and future listings).
`description.txt` / `short-description.txt` are the matching store copy (3,011 / 79 characters; limits are 4,000 / 80).

Publish them with the **Play listing** workflow (`.github/workflows/play-listing.yml`, runs `frontend/firebrat_app/tool/play_listing.py`). It defaults to a dry run that validates and uploads into a draft edit, then discards it. Rebuild the images with `python3 compose.py` (Pillow, macOS Avenir Next).

## What is real

- `dev-*.png`: Pixel 9a screenshots of the debug build, status bar cropped off. `dev-listen-converting`, `dev-listen-waiting`, `dev-pause-resume` and `dev-cast-voices` were captured on the 1.7.2 debug build with Pride and Prejudice (public domain) converting on the device; the book appears under its file name. Sample book: *The Tale of Peter Rabbit* (public domain, Project Gutenberg 14838, three-page excerpt).
- Settings screens show example text typed for the screenshot (character names such as Alice and Mad Hatter, with traits). The cloud LLM screens use `https://openrouter.ai/api/v1` with the API key masked by the app itself; the key was never saved. The "Connected" result is a real call to a free OpenRouter model.
- `library-*.png` and `cover-*.png`: rendered from the real `LibraryScreen` / `BookCover` widgets by `test/store_modern_capture_test.dart`. The nine titles, authors and durations are **illustrative sample data** for public-domain books, not benchmarks and not a bundled catalogue.
- Backgrounds, headlines and phone frames are generated by `compose.py`. No AI-generated imagery.
- No account email, server address or API key appears in any image. Checked before publishing.

Regenerate the widget sources from `frontend/firebrat_app`:

```sh
flutter test test/store_modern_capture_test.dart --dart-define=CAPTURE_STORE_MODERN=true
```

(Font paths in that test point to the local Homebrew Flutter SDK and macOS system fonts.)
